# Οδηγός χρήσης

[English](usage.md) · [한국어](usage-ko.md) · [Türkçe](usage-tr.md)

Αυτός ο οδηγός καλύπτει την εγκατάσταση, το πρώτο backtest του NFI X7, την επιλογή ακριβούς αριθμού αγορών, την επαναχρησιμοποίηση αποθηκευμένου έργου και τις συνήθεις εντολές αποκατάστασης.

## 1. Απαιτήσεις

Υποστηρίζονται τα εξής περιβάλλοντα:

- Linux x86_64 ή ARM64
- macOS σε Apple Silicon
- Windows μέσω κελύφους Linux σε WSL2

Το Docker απαιτείται όταν η μηχανή πρέπει να κατατάξει τις τρέχουσες αγορές Binance, να κατεβάσει δημόσια candles ή να εκτελέσει επίσημη σύγκριση Freqtrade. Τα εγγενή Windows και το PowerShell δεν υποστηρίζονται.

## 2. Εγκατάσταση ή ενημέρωση του CLI

Εγκαταστήστε την τελευταία δημόσια έκδοση με επαλήθευση SHA-256:

```bash
curl -LsSf https://raw.githubusercontent.com/vntrevx/NFI_BackTestEngine/main/install.sh | sh
```

Ανοίξτε νέο τερματικό και ελέγξτε την εγκατάσταση:

```bash
nfi-bte --version
nfi-bte doctor
```

Ενημερώστε μια υπάρχουσα εγκατάσταση:

```bash
nfi-bte update
```

## 3. Λήψη του NFI

Δημιουργήστε έναν κατάλογο εργασίας και κλωνοποιήστε το επίσημο αποθετήριο NFI:

```bash
mkdir -p ~/nfi-backtest
cd ~/nfi-backtest
git clone --depth 1 https://github.com/iterativv/NostalgiaForInfinity.git
cd NostalgiaForInfinity
```

Εκτελέστε το `nfi-bte` μέσα από αυτόν τον κατάλογο NFI. Η αριθμητική επιλογή αγορών χρησιμοποιεί την τρέχουσα πολιτική όγκου και φίλτρων από τον κατάλογο `configs/`.

## 4. Προτεινόμενη πρώτη εκτέλεση

Ξεκινήστε τη διαδραστική ρύθμιση και το backtest:

```bash
nfi-bte run NostalgiaForInfinityX7.py
```

Πατήστε Enter για να αποδεχτείτε τις προτεινόμενες τιμές: λειτουργία Spot, ανταλλακτήριο Binance, γρήγορη δοκιμή BTC, διαχειριζόμενο κατάλογο candles και τις επτά πιο πρόσφατες πλήρεις ημέρες.

Η ερώτηση για τον αριθμό αγορών δέχεται:

| Είσοδος | Αποτέλεσμα |
| --- | --- |
| `1` | Γρήγορη δοκιμή BTC, προτεινόμενη για την πρώτη εκτέλεση |
| `10`, `20`, `40`, `80`, `100` | Ακριβώς τόσες τρέχουσες αγορές, ταξινομημένες από την πολιτική Binance του NFI |
| `all` | Πλήρης στατική λίστα backtest του NFI |
| `custom` | Λίστα που εισάγεται χειροκίνητα και χωρίζεται με κόμματα |

Οι αριθμητικές επιλογές υπολογίζονται μία φορά μέσω της σταθερά καθορισμένης εικόνας Freqtrade. Τα ταξινομημένα σύμβολα αποθηκεύονται στο `.nfi/project.json`, ώστε το έργο να παραμένει αναπαραγώγιμο ακόμη και αν αλλάξει αργότερα ο όγκος συναλλαγών.

## 5. Εκτέλεση με ακριβώς 80 αγορές

Για νέο μη διαδραστικό έργο Spot με την προτεινόμενη περίοδο επτά ημερών:

```bash
nfi-bte run NostalgiaForInfinityX7.py \
  --trading-mode spot \
  --pair-count 80 \
  --yes
```

Ένα φορτίο 80 αγορών για πέντε χρόνια μπορεί να χρειαστεί περίπου 39 GiB μνήμης. Επιβεβαιώστε πρώτα την εκτέλεση επτά ημερών πριν επιλέξετε μεγάλη χρονική περίοδο.

### Αντικατάσταση αποθηκευμένου έργου

Αν υπάρχει ήδη το `.nfi/project.json`, αναδιαμορφώστε το ρητά. Ένας νέος κατάλογος εξόδου αποτρέπει την επανεκκίνηση παλιών αποτελεσμάτων μίας αγοράς:

```bash
nfi-bte init --force NostalgiaForInfinityX7.py \
  --trading-mode spot \
  --pair-count 80 \
  --output-dir .nfi/runs/x7-80-pairs \
  --yes

nfi-bte run
```

Τα δεδομένα candles παραμένουν κοινόχρηστα στο `.nfi/data/binance`. Οι υπάρχουσες λήψεις με έγκυρο hash μπορούν να επαναχρησιμοποιηθούν.

## 6. Ρητή επιλογή αγορών

Επαναλάβετε το `--pair` για κάθε αγορά Spot:

```bash
nfi-bte run NostalgiaForInfinityX7.py \
  --trading-mode spot \
  --pair BTC/USDT \
  --pair ETH/USDT \
  --timerange 20260101-20260108 \
  --output-dir .nfi/runs/x7-btc-eth \
  --yes
```

Για isolated Futures, χρησιμοποιήστε τη λειτουργία Futures και τα κανονικά σύμβολα με το επίθημα του νομίσματος διακανονισμού:

```bash
nfi-bte run NostalgiaForInfinityX7.py \
  --trading-mode futures \
  --pair BTC/USDT:USDT \
  --pair ETH/USDT:USDT \
  --timerange 20260101-20260108 \
  --output-dir .nfi/runs/x7-futures-btc-eth \
  --yes
```

Για αυτόματη επιλογή Futures, αντικαταστήστε τα ρητά `--pair` με `--pair-count 10`, `20`, `40`, `80` ή `100`.

## 7. Επιλογή χρονικής περιόδου

Χρησιμοποιήστε τη μορφή `YYYYMMDD-YYYYMMDD`. Η ημερομηνία λήξης δεν περιλαμβάνεται:

```bash
nfi-bte run NostalgiaForInfinityX7.py \
  --pair-count 20 \
  --timerange 20260101-20260201 \
  --yes
```

Αν παραλείψετε το `--timerange` στη διαδραστική λειτουργία, προσφέρεται η προτεινόμενη περίοδος επτά ημερών. Με το `--yes`, αυτή η περίοδος επιλέγεται αυτόματα.

## 8. Συνέχιση και έλεγχος αποτελεσμάτων

Μετά τη ρύθμιση, εκτελέστε ή συνεχίστε το αποθηκευμένο έργο:

```bash
nfi-bte run
```

Το τερματικό εμφανίζει τον κατάλογο εκτέλεσης πριν αρχίσει η εργασία. Με την
ολοκλήρωση εμφανίζει μια συμπαγή σύνοψη ASCII, τον κατάλογο αποτελεσμάτων και τα
ονόματα των αρχείων αναφοράς και εξαγωγής. Το αναγνώσιμο αποτέλεσμα είναι το
`report.md`, ενώ τα αρχεία JSON και CSV παραμένουν οι μηχαναγνώσιμες συμβάσεις:

```text
.nfi/runs/<strategy-and-timerange>/
├── report.md
├── summary.json
├── trades.csv
├── orders.csv
├── equity.csv
├── verification.json
└── evidence/index.json
```

Το `report.md` χρησιμοποιεί φορητούς πίνακες ASCII τύπου Freqtrade και διακρίνει
ρητά ένα έγκυρο αποτέλεσμα χωρίς συναλλαγές από ένα σφάλμα εκτέλεσης. Η εκ νέου
δημιουργία αναφοράς αφαιρεί ένα παλιό `report.html` και το CLI δεν ανοίγει ούτε
ζητά πλέον πρόγραμμα περιήγησης.

Για να δημιουργήσετε ξανά την αναφορά Markdown και τις μηχαναγνώσιμες εξαγωγές
χωρίς επανάληψη της προσομοίωσης:

```bash
nfi-bte report .nfi/runs/<strategy-and-timerange>
```

Μετά το `nfi-bte update`, μια ολοκληρωμένη εκτέλεση μπορεί να επαναχρησιμοποιηθεί
όταν έχει αλλάξει μόνο η έκδοση του πακέτου. Η μηχανή επαληθεύει την αρχική
ταυτότητα και τα τεκμήρια χωρίς να τα τροποποιεί. Αλλαγή στρατηγικής, ρύθμισης,
αγορών, χρονικής περιόδου ή σημασιολογικού pipeline απαιτεί διαφορετικό
`--output-dir`.

Η μηχανή συνεχίζει μόνο ολοκληρωμένα στάδια με έγκυρο hash. Χρησιμοποιήστε διαφορετικό `--output-dir` όταν αλλάζετε σκόπιμα αγορές, χρονική περίοδο, λειτουργία ή άλλες εισόδους.

## 9. Προετοιμασία δεδομένων χωρίς Native προσομοίωση

Για κατάταξη αγορών, λήψη των απαιτούμενων δημόσιων candles και προετοιμασία εισόδων χωρίς εκτέλεση του backtest:

```bash
nfi-bte run NostalgiaForInfinityX7.py \
  --pair-count 20 \
  --prepare-only \
  --yes
```

Εκτελέστε αργότερα `nfi-bte run` για να συνεχίσετε το αποθηκευμένο έργο.

## 10. Συνήθεις εντολές αποκατάστασης

Εμφανίστε όλες τις επιλογές ρύθμισης και εκτέλεσης:

```bash
nfi-bte run --help
nfi-bte init --help
```

Αν το CLI αναφέρει ότι υπάρχει ήδη αποθηκευμένο έργο, συνεχίστε με:

```bash
nfi-bte run
```

ή αντικαταστήστε σκόπιμα τη ρύθμισή του:

```bash
nfi-bte init --force NostalgiaForInfinityX7.py
```

Αν το Docker ή το Binance δεν είναι προσωρινά διαθέσιμο, επαναλάβετε την ίδια εντολή. Οι τεχνικές λεπτομέρειες αποτυχίας κατάταξης αποθηκεύονται στο `.nfi/pair-selection-error.log`. Μετά την εξάντληση των προσπαθειών λήψης candles, εμφανίζεται η ακριβής διαδρομή του `download-error.log`. Οι έγκυρες μερικές λήψεις candles μπορούν να επαναχρησιμοποιηθούν.
