# NFI Backtest Engine v1.8.0

v1.8.0 extends the source-compiled state runtime to current NFI X7 and restores the
trusted bounded-discovery publication path. It adds current-source exact evidence
without relabeling the existing continuous certificates.

## Current X7 capability

The release qualification freezes NostalgiaForInfinity X7 v17.4.581 at upstream
commit `01b1304afaa2a1385754908817ea91be5149ffc9`, source SHA-256
`628a39e3e626809cebfb4c4b82dcc1725c2a03ee97c5494f091ce489b46d7f03`.
Spot and Futures static reachability report zero reachable stateful gaps, complete
closure, and Native compatibility.

Source-compiled state operands can now declare the maximum history they require.
Programs that omit the field retain the prior two-state default. Invalid, zero, or
excessive bounds fail before simulation. Rust stores only the compiled bound and no
strategy-, pair-, timerange-, SHA-, or expected-result branch was added.

## Independent bounded exact proof

Two compact transition fixtures bind final engine commit
`b72247e8457968f10349f9adc139abc8dd7bf14a` to the v17.4.581 source and its
v17.4.580 baseline:

- Spot `ADA/USDT`, `20251104-20251107`, 24,824,635 logical bytes;
- isolated-Futures `THETA/USDT:USDT`, `20251113-20251117`, 30,718,695 logical bytes.

Both baseline and candidate observe changed target
`3e9e388c81d60ce480eb7d96d6208ade099fe50480f1d2fdd23fed79b46cbcaa`.
Independent Official Freqtrade and Native trade surfaces and full state match at zero
tolerance. The evidence is preserved in draft candidate PRs
[#277](https://github.com/vntrevx/NFI_BackTestEngine/pull/277) and
[#276](https://github.com/vntrevx/NFI_BackTestEngine/pull/276), where Required CI
passes. These compact fixtures qualify the changed route; they are not continuous
five-year certificates.

## Trusted discovery publication

The compatibility workflow now carries reached target identities into transition
assessment and publishes the first pair-bound target event instead of extending a
capture through unrelated later orders. Runtime-generated target fixtures are admitted
by the sealed fixture schema, and one day of surrounding context keeps paired
current/baseline evidence below the unchanged 30 MiB candidate ceiling. Stale,
malformed, partial, cross-mode, or oversized candidates still fail closed.

## Certification and distribution boundary

This remains a product release with `combined_full_x7_certified=false`. The five-year
Spot and Futures certificates remain independently bound to v1.0.0 and v1.1.0. They
are not a same-candidate Spot-versus-Futures certificate and are not combined into a
public 10/10 claim. The immutable historical release-candidate fixtures remain the
distribution regression identity.

Release publication remains build-once: SHA-256-sealed artifacts, required-CI commit
matching, exact fixture evidence for Linux and macOS, and byte-identical promotion
from the release candidate to the stable tag. Linux x86_64 and aarch64 and macOS arm64
are the supported release targets. Windows users run the Linux build and ABI under
WSL2; native Windows fails closed.
