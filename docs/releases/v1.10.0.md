# NFI Backtest Engine v1.10.0

v1.10.0 turns `nfi-bte run` into a structured terminal product flow without changing Native simulation semantics.

## Terminal experience

- A compact NFI ASCII header identifies the selected strategy, timerange, and pair count.
- Interactive terminals show one rotating in-place progress line with stage, percentage, and elapsed time.
- System readiness is reduced to one line. Technical preflight evidence remains available in `.nfi/run-preflight.json`.
- Verification-ledger internals and duplicate result paths no longer crowd normal output.

## Freqtrade-style results by default

A normal `nfi-bte run` now prints the complete result structure:

- backtesting report by pair;
- left-open-trades report;
- entry-tag, exit-reason, and mixed-tag statistics;
- Signal-tag and Grind-level analysis when present;
- summary metrics; and
- strategy summary.

The tables retain configured pairs even when the run produced zero trades. Metrics not sealed by the Native trade surface, such as market change, remain explicitly marked unavailable instead of being inferred.

Use `--no-full-report` when only the compact result card is needed.

## Evidence boundary

Completed runs regenerate only derived files such as `summary.json` and `report.md` so the current presentation is immediately visible. Immutable inputs, `run.json`, the exact trade surface, simulator results, and verification evidence remain hash-checked and unchanged.

This presentation release does not claim a new continuous performance certificate. Existing Spot and Futures certificates remain bound to their original release evidence.

## Upgrade

```text
nfi-bte update
nfi-bte --version
```

The reported version must be `nfi-bte 1.10.0`.
