# NFI Backtest Engine v1.10.6

v1.10.6 expands the terminal startup wordmark so the complete product name is shown
as ASCII art.

## Complete product wordmark

`nfi-bte run` now renders `NFI BACKTEST ENGINE` in one consistent five-row ASCII-art
style. Previously only `NFI` used the large wordmark while `BACKTEST ENGINE` appeared
as plain text on its final row.

The selected strategy, timerange, pair count, and checkpoint-resume status continue
to appear beneath the wordmark without changing the run flow.

## Behavior boundary

This is a presentation-only release. Strategy compilation, Native simulation,
Freqtrade comparison, saved projects, and parity evidence are unchanged.

## Upgrade

```text
nfi-bte update
nfi-bte --version
```

The reported version must be `nfi-bte 1.10.6`.
