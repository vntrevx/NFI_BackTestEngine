# NFI Backtest Engine v1.9.1

v1.9.1 fixes completed-run reuse after upgrading the installed package.

## Completed evidence survives presentation upgrades

Research identities include the package version so an incomplete run cannot silently continue under different engine semantics. The v1.9.0 Markdown presentation release therefore exposed an overly broad boundary: a completed v1.8.4 run with otherwise identical strategy, config, pairs, data, runtime, and semantic pipeline versions stopped with `resume identity differs from the existing research run`.

The runner now recognizes a package-only identity difference for completed runs. It verifies the original identity hash, requires every other identity field to remain exact, validates the preserved simulation checkpoint and result artifacts, and returns the completed evidence without rerunning simulation or rewriting it.

Incomplete runs still cannot cross an identity version. Any changed strategy, config, pair list, timerange, data policy, runtime contract, market snapshot, or semantic component version still fails closed and tells the user to select a different `--output-dir`.

The v1.9.0 `report.md`, ASCII terminal output, result-summary 2.0.0 contract, exact-parity boundary, and release evidence are otherwise unchanged.

Upgrade with:

```text
nfi-bte update
```
