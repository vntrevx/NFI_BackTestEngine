# NFI Backtest Engine v1.15.0

v1.15.0 is the audit-first 10/10 release train for the declared
NostalgiaForInfinityX7 research-backtesting scope. It reuses the existing Native,
resume, performance, and Combined certification foundations and closes only the
remaining product, distribution, and operational gaps.

## Product boundary

- NostalgiaForInfinityX7 is the only Native-supported strategy family.
- NostalgiaForInfinityNext V8 and NostalgiaForInfinityNextGen V9 remain hidden from
  normal selection and run only through explicit, digest-pinned Official fallback.
- Supported platforms are Linux x86_64/aarch64, macOS arm64, and Windows WSL2
  x86_64. Native Windows remains unsupported and fails closed.

## Release integrity

The release builds three wheels and one sdist once. Signed platform evidence binds
four execution slugs to those distributions, with WSL2 intentionally reusing the
Linux x86_64 wheel. GitHub RC, GitHub stable, TestPyPI, and PyPI bytes must retain the
same SHA-256 identities. PyPI publication uses the protected OIDC Trusted Publisher;
no long-lived upload token is accepted.

## Certification boundary

This release may claim `combined_full_x7_certified=true` only when the same candidate
commit and distributions pass both 80-pair, continuous five-year Spot and Futures
certificates, exact trade and required full-state parity, deterministic Native
repetitions, sealed memory and swap limits, and at least 10x preserved-vector speedup
against their immutable Official Oracles.

The fixed public RC must then complete seven operations cycles. Every cycle binds
successful compatibility, discovery, nightly, public installation, and asset-restore
checks to the same commit and public checksum manifest. Stable promotion is blocked
unless cycle 7 seals the complete 10/10 audit.

## Upgrade

```text
nfi-bte update
nfi-bte --version
```

The reported version must be `nfi-bte 1.15.0`.
