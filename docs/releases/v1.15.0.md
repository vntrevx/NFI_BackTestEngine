# NFI Backtest Engine v1.15.0

v1.15.0 is a product improvement release for the declared NostalgiaForInfinityX7
research-backtesting scope, not a 10/10 or Combined Full X7 certification release.
It reuses the existing Native, resume, performance, and certification foundations.

## Improvements

- Qualified, explicit-consent Official fallback for sealed legacy strategy sources;
  unsupported strategies remain excluded from normal Native selection.
- Installed-wheel clean-room journey, recovery checks, and evidence-preserving
  lifecycle tooling.
- Four-platform distribution evidence, including actual WSL2 execution using the
  Linux wheel, with build-once checksums and an SPDX software bill of materials.
- Additional independently captured Spot/Futures regression fixtures and a generic
  Futures zero-liquidation handling fix.
- Full X7 certificate reuse, stricter source/package identity checks, and validated
  immutable certificate storage before combined scoring. These are certification
  infrastructure improvements, not completed five-year certification.

## Product boundary

- NostalgiaForInfinityX7 is the only Native-supported strategy family.
- NostalgiaForInfinityNext V8 and NostalgiaForInfinityNextGen V9 remain hidden from
  normal selection and run only through explicit, digest-pinned Official fallback.
- Supported platforms are Linux x86_64/aarch64, macOS arm64, and Windows WSL2
  x86_64. Native Windows remains unsupported and fails closed.

## Release integrity

Publication requires successful same-commit automated CI and release-build checks,
installed-package checks, and representative exact Spot/Futures platform evidence.
The release builds three wheels and one sdist once. Signed platform evidence binds
four execution slugs to those distributions, with WSL2 intentionally reusing the
Linux x86_64 wheel. GitHub RC and stable assets must retain the same SHA-256
identities; promotion verifies downloaded bytes and installer behavior.
GitHub Releases is the distribution channel for this release. PyPI/TestPyPI
publication remains planned and is not claimed as available. Its existing OIDC,
attestation, and cross-channel checksum requirements remain in place for activation.

## Certification boundary

`combined_full_x7_certified=false`. This release does not claim a new same-candidate
80-pair, five-year Spot/Futures certificate, a measured 10x speedup for this candidate,
or completion of the seven-cycle operations soak and final 10/10 audit. Prior Spot
and Futures certificates remain bound to their original versions and inputs.

The separate combined-certification gates remain unchanged. Remaining integration,
long-run certification, and operations audit work is retained in
`planning/roadmap-state.json`; no future certified release version is assigned.
Latest upstream branch coverage is not guaranteed: unknown active semantics continue
to fail closed, and representative fixtures do not certify arbitrary X7 revisions.

## Upgrade after publication

These instructions apply only after the release passes its gates and is published.

```text
nfi-bte update
nfi-bte --version
```

After upgrading to the published release, the reported version must be
`nfi-bte 1.15.0`. A local version string alone is not certification evidence.
