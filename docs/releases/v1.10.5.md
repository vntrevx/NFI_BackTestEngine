# NFI Backtest Engine v1.10.5

v1.10.5 restores deterministic Futures free-wallet projection for exact full-state parity. Native simulation and trade semantics are unchanged.

## Full-state parity repair

Freqtrade and the native engine derive Futures free balance through different, economically equivalent arithmetic paths. Their raw values can differ below one nano-USDT because of float representation, such as `8022.005733333` versus `8022.005733333333`.

Full-state projection now canonicalizes both Futures values to one nano-USDT with half-even rounding. This remains finer than exchange precision and restores a stable byte representation. Spot wallet projection continues to preserve the caller's exact value.

## Nightly validation

The repair restores exact trade and state parity for all seven fixtures that failed the nightly full-state shards. The deduplicated summary failure was downstream of those shard failures, not a separate defect.

## Upgrade

```text
nfi-bte update
nfi-bte --version
```

The reported version must be `nfi-bte 1.10.5`.
