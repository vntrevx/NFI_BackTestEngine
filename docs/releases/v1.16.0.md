# NFI Backtest Engine v1.16.0

v1.16.0 adds capability-checked Native support for NostalgiaForInfinityX8 alongside
X7. Published as a stable product release on 2026-09-08, it promotes the validated
v1.16.0-rc.1 distributions without rebuilding. Strategy admission remains specific
to the supplied source, configuration, and frozen market inputs.

Update an installed CLI with:

```bash
nfi-bte update
nfi-bte --version
```

The expected version is `nfi-bte 1.16.0`. Existing RC installations already contain
the same package bytes and need no reinstall.

## X8 behavior

- Compile the supplied X8 indicators, entry signals, tags, exits, stake and leverage
  callbacks, order state, and position adjustments into the Native Rust execution path.
- Support the qualified short top-coins exits, grind/rebuy and buyback behavior,
  source systems v3/v3.2/v4, virtual fees, constructor and resolver settings,
  stop/ROI/trailing controls, trade slots, and exchange order/stake bounds.
- Evaluate applicable source exits on the opening candle, matching the captured
  official high-leverage case. Older sealed simulator contracts retain their behavior.
- Add `system tune --cpu-process-limit`. Official comparison inherits the run's CPU
  and memory caps; automatic hardware recalibration preserves chosen limits.
  Defaults continue to derive workload capacity from the host without a fixed 4 GiB cap.

## Evidence and limits

The pre-release Linux qualification includes 54 retained cases (53 X8 and one X7
regression): 136 trades, 743 orders and 103,968 portfolio states at zero tolerance.
Most cases deliberately exercise individual branches through disclosed signal or
configuration transformations. An additional pair of unchanged-source X8 captures
covers three days of ETH Spot and isolated Futures: four naturally generated long
trades, eight orders, 1,728 portfolio states and 147 callback-state snapshots match
official Freqtrade exactly. These include strategy exits and a funding payment.

The earlier complete Linux suites passed 2,535 Python tests and 458 Rust tests;
55 Python tests were skipped and two Rust tests ignored. Subsequent resource changes
passed 123 focused Python tests. The final candidate commit subsequently passed
[Required CI](https://github.com/vntrevx/NFI_BackTestEngine/actions/runs/34202176412)
and [installed-wheel release checks](https://github.com/vntrevx/NFI_BackTestEngine/actions/runs/34202171035),
including original-X8 Spot/Futures trade and full-state equality on Linux
x86_64/ARM64, macOS ARM64 and Windows WSL2 x86_64. The repository-independent
clean-room installation journey also passed. See
[X8 support](https://github.com/vntrevx/NFI_BackTestEngine/blob/main/docs/x8-support.md)
for source hashes, capture recipes and the precise tested scope.

This release does not claim every X8 configuration, every exchange, broad natural
short-signal coverage, a five-year X8 certificate, or live-trading support.
Position stacking and cross-margin multi-currency collateral remain unsupported.
Unknown exact semantics fail closed. Existing X7 certificates retain their original
version and input identities; `combined_full_x7_certified` remains false.

## Distribution

Supported execution platforms are Linux x86_64/aarch64, macOS arm64 and Windows
WSL2 x86_64. Native Windows is unsupported. Release wheels passed both the existing
X7 platform checks and the bounded original-X8 Spot/Futures checks.

The [stable release](https://github.com/vntrevx/NFI_BackTestEngine/releases/tag/v1.16.0)
is distributed through GitHub Releases and selected by the default installer and
`nfi-bte update`. PyPI publication remains planned.

The [stable promotion workflow](https://github.com/vntrevx/NFI_BackTestEngine/actions/runs/34228035469)
verified the candidate checksums, supply-chain identity, installed version and an
exact full-state fixture before publication. It then downloaded the stable assets,
proved all 13 files byte-identical to the RC, and passed the Linux and macOS latest
installer audits. The RC and its evidence remain available under their original tag.
