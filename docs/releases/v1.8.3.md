# NFI Backtest Engine v1.8.3

v1.8.3 turns the config-free first run into a beginner-oriented workflow and makes long operations visibly alive.

## Beginner first run

A fresh NFI checkout now explains that Enter accepts the recommended value, offers a one-pair quick test or NFI's maintained static backtest list, selects engine-managed candle storage, and defaults to the most recent seven complete days. NFI's modular configuration remains untouched.

The run prints the results directory and future HTML-report path before work begins. A live terminal line then reports the current stage, overall stage percentage, and elapsed time. Completion prints the report URI and all generated HTML, JSON, and CSV locations.

## Reliable public candle downloads

X7 requires a BTC market-reference series in addition to the selected trading pairs. The candle stage now states both counts instead of silently downloading BTC.

Transient Binance and network failures receive three bounded attempts with short backoff. Partial downloads remain reusable. If all attempts fail, the CLI returns a short rerun instruction and writes the complete Freqtrade diagnostic to `download-error.log` under the run directory instead of printing an internal Python traceback.

## Compatibility and evidence boundary

The simulation, pair ordering, exact-parity, and fail-closed contracts are unchanged. The existing independently sealed Spot and Futures certificates remain version-bound; this usability release does not claim a new combined or continuous performance certificate.
