# NFI Backtest Engine v1.10.4

v1.10.4 replaces the guided restart's raw strategy-file prompt with a real strategy selection menu. Native simulation semantics are unchanged.

## Strategy selection

After choosing a new guided setup, the CLI discovers strategies from the NFI checkout and presents numbered choices:

```text
Available strategies:
  1. NostalgiaForInfinityX7 (current)
  2. NostalgiaForInfinityX6
  3. NostalgiaForInfinityX5
  4. NostalgiaForInfinityX4
  5. NostalgiaForInfinityX3
  6. NostalgiaForInfinityX2
  7. NostalgiaForInfinityX
Choose strategy [1]:
```

The current strategy is marked, placed first, and selected by Enter. Other NFI generations are ordered newest first. Selecting an entry loads that file and analyzes its actual strategy class before continuing to trading mode, exchange, market count, data, and timerange.

Strategies in standard Freqtrade `user_data/strategies` and `strategies` directories remain discoverable. Duplicate names include their relative paths for disambiguation.

## Evidence boundary

Strategy selection does not modify the saved project. The project changes only after the guided setup completes, and prior configs and run outputs remain untouched.

## Upgrade

```text
nfi-bte update
nfi-bte --version
```

The reported version must be `nfi-bte 1.10.4`.
