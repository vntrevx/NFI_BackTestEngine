# NFI Backtest Engine v1.11.0

v1.11.0 turns the existing exact-parity engine into a clearer day-to-day product while
preserving the simulation and certification boundaries.

## Guided strategy selection

`nfi-bte strategy list` derives support from each source's compiled capabilities.
Normal selection shows compatible strategies only. `--show-unsupported` explains
legacy, invalid, or semantically unsupported sources without presenting them as valid
run choices. Neither catalog nor simulator branches on a strategy name, pair,
timerange, source hash, or expected result.

The no-argument interactive home now offers the common workflow, while `nfi-bte
help --all` retains every expert and certification command. Setup checks strategy
compatibility before writing a project.

## Observable operations

Active runs atomically maintain `progress.json`, including PID, phase, percentage,
elapsed time, and measured ETA when available. `nfi-bte status` reads that durable
state and marks a dead active PID as interrupted.

`nfi-bte doctor --json` emits a versioned report with stable codes, severity,
remediation, and safe auto-fix metadata. `--fix` is limited to creating the managed
`.nfi` root. Exported diagnostics remain local and exclude environment variables,
credentials, and telemetry.

## Reproducible discovery inputs

Spot and Futures branch discovery policies now bind both the complete market catalog
and selected 80-pair market snapshot by SHA-256. Spot candidates use quote volume
captured in the frozen catalog, not a live ticker during discovery. Mode, pair set,
path boundary, and hashes are revalidated on first use and resume.

Discovery candles now come from completed-month Binance Public Data archives rather
than exchange REST endpoints. Every ZIP is checked against its published SHA-256 and
CRC before conversion, and each output carries a resumable source manifest binding
pair, timeframe, base/mark/funding role, archive identities, and final Feather bytes.
Missing pre-listing months are explicit; internal missing months and unproven caches
fail closed.

The CPython 3.14 Linux `python-rapidjson` wheel pin now uses the correct manylinux URL
and digest. Data-download containers copy the sealed dependency inventory into their
private executable tmpfs, avoiding both host mutation and duplicate mounts.
Infrastructure failures no longer consume a discovery shard or masquerade as an
unsupported strategy.

## Certification boundary

This release does not relabel historical Spot and Futures certificates as a new
same-candidate combined certificate. Native simulation semantics and zero-tolerance
parity comparison are unchanged; unknown active behavior still fails closed.

## Upgrade

```text
nfi-bte update
nfi-bte --version
```

The reported version must be `nfi-bte 1.11.0`.
