# NFI Backtest Engine v1.9.0

v1.9.0 replaces the browser-oriented result page with a compact, portable Markdown report.

## Freqtrade-style Markdown result

Every completed, prepared, or safely blocked run now writes `report.md` instead of `report.html`. The report uses fenced ASCII tables for the overview, core metrics, pair and tag breakdowns, futures lifecycle, trades, verification, and result-file index. It has no scripts, remote assets, analytics, or network requests and can be read directly in a terminal, editor, or GitHub-compatible Markdown viewer.

A completed run with zero trades now says explicitly that no entries completed and that the result is valid rather than an execution error. Empty order and verification details are collapsed so this common first-run result stays short.

The terminal result is also a compact ASCII card. It shows the strategy, period, mode, lane, pair and trade counts, profit, balance, win rate, drawdown, runtime, memory, and official-parity state, then prints one results folder with the report and machine-export names.

## Clean migration

Report regeneration deletes a stale sibling `report.html`. The CLI no longer exposes `--open-report`, prompts to open a browser, or imports a platform browser opener.

The derived `summary.json` contract advances from `1.2.0` to `2.0.0`. Its artifact map replaces `html_report` with `markdown_report: "report.md"`. `run.json`, `trade-surface.json`, verification evidence, CSV schemas, and exact-parity authority are unchanged.

## Compatibility and evidence boundary

This release preserves current-source compatibility for X7 v17.4.587 at upstream commit `95b76043c3f610e0760e191deebd12304bfadbf8`, the v1.8.4 pair-selection workflow, and the supported Linux, macOS, and WSL2 installation paths. Existing Spot v1.0.0 and Futures v1.1.0 continuous certificates remain version-bound; this presentation release does not claim a new continuous performance certificate.

Upgrade an installed CLI with:

```text
nfi-bte update
```
