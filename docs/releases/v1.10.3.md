# NFI Backtest Engine v1.10.3

v1.10.3 separates continuing a saved project from starting genuinely new guided work. Native simulation semantics are unchanged.

## Saved-project startup

Interactive `nfi-bte run` now begins with the saved project identity and asks:

```text
Start a new guided setup instead? [y/N]:
```

- Enter or No continues the saved strategy, settings, and output.
- Yes asks for the strategy file; the previous strategy is offered only as the default.
- The guided flow then asks for trading mode, exchange, market count, data, and timerange before normal CPU execution consent.

Choosing X7 therefore loads and analyzes X7 before generating its new safe configuration.

## Evidence preservation

A guided restart writes a separate generated config such as `first-run-config-new.json` and selects a fresh output. Existing configs, completed output, checkpoints, and evidence are not deleted or overwritten. Cancelling at CPU consent keeps the newly selected setup for a later run while prior evidence remains available.

Unattended `--yes` continues the saved project. `--new-run --yes` remains the explicit automation path for fresh output with exactly the same saved settings.

## Upgrade

```text
nfi-bte update
nfi-bte --version
```

The reported version must be `nfi-bte 1.10.3`.
